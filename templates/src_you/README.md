# Private state template

Copy this directory into a **private, user-controlled authoritative store**. Do
not fill it with real data inside a public fork of the framework repository.

Start at [`00_SYSTEM_MANIFEST.md`](00_SYSTEM_MANIFEST.md). Keep only files that
serve a real purpose; the template is modular, not a mandate to populate every
section.

Intentional template tokens use double braces, for example
`{{AUTHORITATIVE_STORE}}`. Replace or remove them during bootstrap.
