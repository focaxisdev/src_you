# Fictional examples

Every person, organization, date, project, and state record in this directory is
synthetic. The examples demonstrate boundaries and lifecycle behavior; they are
not derived from a real user's profile or state system.

- [`fictional-career/`](fictional-career/) shows durable global career state
  versus detailed job-search project state.
- [`fictional-learning/`](fictional-learning/) shows a high-level learning goal
  versus lesson micro-state.
- [`conflict-resolution-example.md`](conflict-resolution-example.md) shows
  supersession and stale Memory handling.
